# NetSentinel

Analizador de seguridad de red automatico para usuarios no tecnicos. Escanea tu red, detecta vulnerabilidades y entrega un diagnostico en lenguaje simple con instrucciones para resolver cada problema.

## Stack

- **Frontend**: Angular 21 + Electron
- **Backend**: Spring Boot + Java 21
- **Sandbox**: Rust + WSL2 + Kali Linux
- **Bases de datos**: PostgreSQL + Neo4j + Redis
- **Inteligencia**: Claude API
- **Installer**: NSIS + PowerShell

## Estructura del proyecto

```
NetSentinel/
├── frontend/    # Angular + Electron (interfaz de escritorio)
├── backend/     # Spring Boot (API REST, logica de negocio)
└── sandbox/     # Rust (ejecucion segura de herramientas de seguridad)
```

## Requisitos de desarrollo

- Node.js 20+
- Java 21
- Rust 1.70+
- Angular CLI
- Maven 3.9+
- WSL2 con Kali Linux
